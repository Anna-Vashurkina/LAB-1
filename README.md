# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Структура проекта
* `data/` — исходные файлы данных и скрипт сборки.
* `notebooks/` — Jupyter Notebook с выполнением лабораторной работы.
* `report/` — текстовый отчёт о качестве данных (`quality_report.md`).

## Инструкция по запуску
1. Убедитесь, что все исходные файлы (`sightings.csv`, `weather.csv`, `locations.csv`, `crime_incidents.csv`) находятся в папке `data/`.
2. Для генерации объединенного датасета запустите скрипт:
