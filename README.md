
## Инструкция по запуску в Google Colab

Если вы хотите запустить ноутбук в облаке (Google Colab), выполните следующие шаги:

1. Откройте файл `notebooks/01_data_understanding.ipynb` в Google Colab.
2. В первой ячейке ноутбука уже содержится код для скачивания всех необходимых CSV-файлов напрямую из этого репозитория GitHub. Просто запустите первую ячейку — данные загрузятся автоматически.
3. Выполните все ячейки последовательно: `Среда выполнения` -> `Выполнить все`.
4. Убедитесь, что в файловой системе Colab появился файл `full_dataset.csv` (он создается в процессе выполнения).

## Описание этапов работы

В ходе лабораторной работы были выполнены следующие этапы:

1. **Постановка задачи (Business Understanding):** Определен условный заказчик (городская администрация) и сформулированы задачи ИАД (описательная аналитика и поиск аномалий).
2. **Паспорт датасета (Data Understanding):** Загружен и объединен датасет из 6 исходных таблиц. Определен размер (86 631 строка, 70 столбцов), типы данных и сформулированы гипотезы о смысле каждого признака.
3. **Аудит качества данных:**
   * Выявлены пропуски (наибольшие — в признаках, связанных с преступлениями, 92.99%).
   * Проверены дубликаты (полных дубликатов не обнаружено).
   * Найдены выбросы (например, `estimated_speed_kmh` до 908 км/ч) и логические ошибки (отрицательное время `minutes_from_nearest_crime`).
4. **Разведочный анализ (Mini-EDA):** Построены визуализации (гистограмма температуры, bar chart по районам, scatterplot, boxplot) и сформулированы выводы.
5. **Текстовый отчет:** Результаты аудита оформлены в файле `report/quality_report.md` с таблицей проблем и планом улучшения качества данных.
